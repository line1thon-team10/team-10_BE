# Team10 개발 task 목록

2026-11-14 계획. 각 task는 한 에이전트가 검증 가능한 결과를 넘기는 단위이며 한 커밋을 뜻하지 않는다. 상세 선행 조건·수정 범위·엣지케이스·외부 조건·현재 상태는 [development-tasks.json](development-tasks.json)이 기준이다. 실행·검수 규칙은 [오케스트레이션 계획](development-orchestration.md)을 따른다.

필수 **82개**, 선택 **1개**. 선택 OPT-01을 제외한 나머지는 이번 계약 완료 범위다. 이 목록의 76개 API는 기존 완료 경로11개와 후속task 담당65개(선택2개 포함)로 빠짐없이 매핑했다. 기존 경로를 담당task에 넣은 것은 구현이 없다는 뜻이 아니라 계약 보정/회귀 검증이 남았다는 뜻이다.
