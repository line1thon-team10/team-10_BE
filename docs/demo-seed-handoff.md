# FE 전달: AI 데모 패키지 시드 값표

2026-11-14 확정. 사용자 승인으로 11/12 합의(인공지능·데이터베이스·운영체제)를 구현한다. 이 문서는 `feat/demo-package`의 값이며 **운영 배포 완료를 의미하지 않는다**. 배포 뒤 새 익명 세션 또는 명시적인 seed/reset에 적용된다. 기존 사용자 데이터를 자동 변환하거나 초기화하지 않는다.

## 근거와 변경 이유

- FE `docs/team-requests-1112.md`, `docs/policy-and-backend.md`: AI 데모 패키지와 42분 집중 시연을 합의했다.
- BE `docs/api/decisions.md`: 패키지 기반 시드로 합의했으나 기존 구현은 DS/OS/NW·집중 세션 없음이었다. **BE 구현 누락을 보정**한다. FE가 과목을 잘못 정한 사례가 아니다.
- 실제 파일/목차: AI submodule `6d74ffb6c455a306e912252013d76f93e30a6210`의 `data/demo/*.pdf`, `data/ground_truth/*.json`. 공개 BE에 원본 파일을 복사하지 않고 고정 submodule에서 읽는다.
- 시험일·목표·오늘 완료 상태는 승인된 시연 설정이다. PDF에서 시험일·목표를 추출한 값이 아니다. 목표는 점수 예시이며 학교의 실제 성적 기준이 아니다.
- 구 시드의 문항 77개·DS/OS/NW 페이지를 이름만 바꿔 재사용하지 않는다. 패키지 주제에 맞춰 작성한 로컬 문항 45개를 사용하며 실시간 AI 생성 결과라고 표시하지 않는다.

## 과목·시험·단원

`empty`는 2026-11-03, 과목·계획·집중 세션이 없는 상태다. `day9`·`overdue`는 2026-11-09이며 아래 과목을 사용한다. PDF는 각 30p, 시험 범위는 3–29p의 27p다. 표지·목차·마지막 페이지는 학습 범위에 넣지 않는다. 단원 난이도는 데모용 `low`다.

| 코드 | 과목 / 파일 | 시험일 | 목표 | 단원 1 (p.3–11) | 단원 2 (p.12–20) | 단원 3 (p.21–29) |
|---|---|---|---|---|---|---|
| AI | 인공지능 / artificial_intelligence.pdf | 2026-11-12 | A+ / 90점 | 머신러닝 기초 | 지도학습 알고리즘 | 모델 평가와 활용 |
| DB | 데이터베이스 / database.pdf | 2026-11-16 | B+ / 80점 | 관계형 데이터베이스 기초 | SQL 조회와 조작 | 정규화와 트랜잭션 |
| OS | 운영체제 / operating_system.pdf | 2026-11-18 | 통과 / 60점 | 프로세스와 스레드 | CPU 스케줄링 | 교착상태와 기아상태 |

코드는 내부 식별용이다. API의 subjectId/taskId/sessionId/materialId는 사용자·초기화마다 새 UUID이므로 FE가 AI/DB/OS 또는 예제 UUID를 요청 ID로 고정하면 안 된다. `/api/today`, `/api/books`, `/api/study/sessions/active` 응답에서 실제 ID를 받는다.

## 오늘 할 일과 상태

| 오늘 할 일 | 페이지 / 예상 시간 | day9 | overdue |
|---|---|---|---|
| 인공지능 2단원 | p.12–20 / 9p / 25분 | todo, 집중 42분 진행 중 | todo, 집중 없음 |
| 데이터베이스 2단원 | p.12–20 / 9p / 25분 | done | done |
| 운영체제 2단원 | p.12–20 / 9p / 25분 | done | todo |

- `day9`: 2/3개 완료, **18/27p → API rate=67**. 정확한 비율은 66.7%지만 기존 API는 정수 반올림이다. 전체 퀴즈는 잠겨 있고 DB·OS 과목별 퀴즈는 열려 있다.
- 집중 종료 후 인공지능을 `result:partial,toPage:13`으로 기록하면 2p가 더해져 **20/27p → rate=74**, 전체 퀴즈가 열리고 `event.type=box,reason=dayClose`가 나온다. 종료한 `sessionId`를 기록 요청에 전달한다.
- `overdue`: 1/3개 완료, **9/27p → rate=33**. 다음 날 이동 시 미완료 18p(AI 9 + OS 9)에 대해 `judgment=replan`이다.
- day9를 2p만 기록한 뒤 다음 날로 가면 AI 잔여 7p도 현행 평균 일일 분량 기준을 넘어 `replan` 대상이다. 구 데이터의 “7p는 carry, 38p는 replan” 수치를 새 목업에 그대로 쓰지 않는다. 이 PR에서 분배 판정 공식을 바꾸지는 않는다.

## 준비도·위험 단원·퀴즈

숙달도는 저장된 15개 풀이 이력을 AI `learning_metrics`의 로컬 계산 함수로 계산한다. 외부 API 키는 필요 없다. 첫 단원 점수: AI1=90(stable), DB1=40(risk/회복 모드), OS1=80(stable). 2·3단원은 아직 채점하지 않아 점수가 null이다. 회독 근거에는 실제 학습 기록 ID와 완료 페이지를 넣는다.

| 시드 | 인공지능 준비도 | 데이터베이스 준비도 | 운영체제 준비도 |
|---|---|---|---|
| day9 초기 | 30% | 27% | 53% |
| overdue 초기 | 30% | 27% | 27% |

준비도는 서버가 학습 페이지와 숙달도로 계산한 값이다. 기록/채점 뒤 재조회하고 FE에 위 값을 고정하지 않는다. DB 1단원에서 위험 책 장면을 볼 수 있다.

오늘 퀴즈는 과목별 새 문제 5개 + 취약 문항으로 **AI 6개 / DB 8개 / OS 6개**다. 전체 문제은행은 9단원 × 5개 = 45개로 OX·단답형·서술형을 포함한다. 근거 페이지와 문장은 실제 PDF에서 읽는다. AI2 마지막 문항은 p.16 랜덤 포레스트 서술형이다.

키 없는 서술형 시연은 아래 답안을 정확히 입력한다.

> 여러 결정 트리를 학습시켜 분류 결과를 투표로 정합니다.

AI 채점 실패 시 이 문항 버전·질문·정답·답안 전체의 SHA-256이 저장 예시와 일치하면 70점 및 맞힌 점/빠진 점을 반환한다. `essayGrading:saved`로 표시한다. 이 값은 시연용으로 작성한 평가 예시이며 실제 AI 채점 결과를 보장하는 값이 아니다. 다른 답안, 다른 버전, 수정한 질문에 임의 70점을 주지 않고 `503 AI_FAILED`로 응답한다. 빈 답안은 기존 규칙대로 0점이다. 새 저장 예시로 구 `DS3-06` 코드만 보고 무조건 70점을 주던 BE 동작을 보정했다.

## 집중 시연 절차

1. `/api/demo/reset` 또는 `{seed:day9}`로 초기화한다. 새 익명 세션도 DEMO_MODE일 때 같은 시드다.
2. `/api/study/sessions/active`로 활성 세션을 받는다. 같은 태스크로 시작 요청을 보내도 해당 세션을 이어서 사용한다.
3. [종료] → 종료한 sessionId로 p.13까지 부분 완료 기록 → 하루 마무리 박스 → 퀴즈로 진행한다.
4. 별도 밀림 장면은 `{seed:overdue}`로 바꾼 뒤 [다음 날로]를 누른다.

42분은 **시드 생성 시 실제 UTC 시각 − 42분**으로 만든 초기 경과 시간이다. 학습 날짜는 2026-11-09지만 측정 시각을 과거 날짜로 고정하지 않는다. 화면을 열 때마다 42분으로 재설정하지 않고 실제 시간이 흐른다. 예상 25분의 2배인 50분에서 확인을 요청하므로 초기화 8분 후 checkIn, 무응답 18분 후에는 50분 시점으로 자동 종료되어 속도 보정에서 제외된다. 정확한 42분 장면은 초기화 직후 진행한다.

집중 세션이 running/paused이면 다음 날 이동은 `409 SESSION_RUNNING`이다. `[종료]`만으로 태스크 완료·페이지 기록을 만들지 않는다. reset은 해당 사용자의 세션·구간을 교체하고 타 사용자에게 영향이 없다. empty/overdue에는 집중 세션이 없다.

## 나머지 계획과 FE 작업

과목별 1단원 완료일: AI 11/3, DB 11/4, OS 11/5. 3단원 학습일: AI 11/10, DB 11/12, OS 11/16. 총복습: AI 11/11, DB 11/15, OS 11/17. 모든 태스크는 25분이고 총복습은 페이지 범위가 없는 태스크다. 새 범위 9개 + 총복습 3개 = 12개 태스크이며 기존 26개와 다르다.

FE 담당자 변경 항목:

- 목업 과목·단원·범위·진행률·준비도·문항 수·시험일을 위 값으로 교체. 목업 API 응답 모양은 유지한다.
- 42분 활성 세션을 day9에만 넣고 종료·기록·날짜 이동 순서를 맞춘다.
- 기존 AVL/BST 추천 질문을 제거한다. BE 홈은 실제 과목·오늘 단원을 사용한다.
- 구 7/13/5문항, 58% 진행률, 38p 밀림, DS3 점수 변화 문구를 제거한다.
- firstExam:null 및 날짜 이동 Idempotency-Key 보완은 [기존 전달 사항](api/session.md)을 유지한다.

이 PR은 FE 목업 파일을 직접 수정하지 않는다. PDF 제공/업로드·AI 실시간 생성·분배안 전체 계약·집중/기록 동시성 전체 보정은 후속 구현 범위다. 저장 시드 문항으로 오늘 퀴즈는 가능하지만 단원당 5문항을 소비한 뒤의 '더 풀기'에는 별도 문제 공급이 필요하다.

## 적용과 되돌리기

새 DB migration은 없다. 부모 스택의 revision이 적용된 서버에서 신규 이미지와 AI 데이터 폴더가 함께 필요하다. 구 사용자는 기존 자료를 유지한다. 새 값은 새 익명 사용자 또는 사용자 자신에 대한 seed/reset으로만 적용한다.

시드 초기화는 해당 사용자의 기존 학습 데이터를 삭제하므로 기존 시연 데이터를 보존하려면 새 익명 세션을 사용한다. 코드 revert/이전 이미지 복구는 이미 초기화한 데이터를 복원하지 않는다. 실제 운영 배포·백업·복구는 기존 배포 절차와 워크스페이스 루트의 `RPI-DEPLOYMENT-ROLLBACK.md`를 따른다.
