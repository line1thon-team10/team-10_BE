# 일반 사용자 날짜 마감

`DayRolloverService`는 인증된 일반 사용자 요청에 앞서 `last_assessed_date` 다음 날부터 현지 어제까지 순서대로 정산한다. 데모 사용자에는 실행하지 않으며 데모 next-day의 날짜/응답 재생은 그대로 유지한다.

- 인증과 날짜 마감은 요청 본문을 처리하는 트랜잭션보다 먼저 독립적으로 커밋한다. AI 라우트가 요청 연결을 반환하거나 요청한 리소스 조회가 실패해도 이미 끝난 시스템 날짜 마감을 되돌리지 않는다. 날짜 정산 자체의 실패는 모든 해당 날짜 변경을 롤백한다.
- 사용자 잠금을 획득한 뒤 상태를 다시 읽고 같은 날짜의 중복 마감을 막는다. 다른 사용자와의 자료·이력은 조회/변경하지 않는다.
- 자정은 사용자의 IANA 시간대를 따른다. 집중 구간은 자정을 가로지를 수 있으므로 새 세션을 만들거나 강제로 종료하지 않는다. 실제 확인 기한 만료만 먼저 정산한다. 아직 진행/일시정지 중인 태스크는 마감 시 고정하고 기존 집중 시간은 날짜 조회에서 실제 구간의 교집합으로 계산한다.
- 날짜별 분모를 확정하고 이월/분배안 판단을 연결한다. 시험일에는 새 배치하지 않으며 시험일 다음 날에 `exam_finished`로 보관한다. 기록·세션·학습 범위·퀴즈 이력을 지우지 않는다.
- 계획 없는 사용자도 마지막 정산일을 초기화한다. 첫 정산 표식이 없는 기존 계획은 생성/승인/첫 배치의 가장 이른 날짜를 기준으로 정산한다. 서버 시계 또는 시간대 변화로 오늘이 이미 정산한 날짜 이전이면 날짜를 되감지 않는다.

로컬 검증은 `tests/e2e/test_day_rollover.py`와 기존 인증·집중·데모 테스트로 수행한다. GitHub CI와 push는 전체 구현 완료 후 별도 단계다.
