# 계약 완료 판정 시나리오

이 목록은 아직 실행한 테스트 결과가 아니라 구현 이후 통과해야 할 수용 기준이다. 기본 준비: 서로 다른 사용자 A/B, 빈 사용자, 정상 PDF/스캔 PDF/손상 PDF, 0/69.99/70/100% 계획, 완료/미완료 퀴즈, 반복 일정, 동일 데이터의 PostgreSQL 테스트 DB.

| 영역 | 정상 | 경계/실패/동시성 |
|---|---|---|
| 세션 | 발급 후 조회, 데모 seed별 상태 | 헤더 없음/잘못된 UUID/다른 사용자 객체; 빈 firstExam 화면 표시 |
| 온보딩 | 목표 확인→done, 일정 CRUD | 빈 과목이면 done=false; 모호한 자연어로 임의 일정 생성 금지; 중복 요일·역전 시각 거절 |
| PDF | 업로드→running→done, 파일 열기 | 합의된 업로드 크기 경계(현재 미정), 비PDF/잠금/손상, 실패→재접수, 정상 OCR은 출제 가능·저품질만 quizless, 사용자 간 캐시 격리 |
| 단원 | 편집·시험범위 변경 | 범위 겹침/0쪽/실제 PDF 초과/중복 no, 구조 교체 시 구 작업 완료 무효화, 과거 문항 참조 유지 |
| 계획 | 가용시간 내 분할→승인 | 총페이지 보존, 모든 태스크15~60분, 시험 당일 제외, 0 가용시간, 60분 초과 태스크 분할 |
| 후보 | 미리보기 후 ID로 승인 | 두 탭 후보 교차 적용 금지, 날짜·의존 revision 변경, 같은 후보 재승인 중복 효과 없음 |
| 학습 기록 | done/partial/none와 페이지 정정 | 첫/마지막 페이지, 비연속 범위, 다른 세션/실행 중 세션 거절, 같은 기록 재전송, 완료→부분 정정 |
| 집중 | 시작→멈춤→재개→종료 | 동시 시작 한 개만, 중복 pause/end, 자정/멈춤시간 제외, 2배+10분 정확한 자동 종료 |
| 퀴즈 개방 | 전체 또는 과목70% | 반올림으로69.99%를 열지 않음, 출제가능 분모0, 잠긴 문항 정답 유출 없음 |
| 제출 | 문항 전체 저장→채점→결과 | 중복/타인/누락 문항, 잘못된 choice/confidence, 답안 저장 후 AI 실패·프로세스 재시작 |
| 제출 재시도 | 동일 답안은 같은 결과 | 동시 두 제출 숙달도 한 번만, 다른 답안 거절, 점수85/84.99, 유효하지 않은 AI 점수 거절 |
| 저장 결과 | 동일 입력 결과 재사용 | 다른 답안·사용자·구조 버전에는 fallback 금지, saved 요청 시 외부 AI 호출0 |
| 점수/책 | 진도×숙달도, 일별 회복 상한 | 0분모, 점수없음 null, 최근9/10/19/20건, +5/+15, 49/50/79/80, 이월 책 중복 없음 |
| 복습 | 예정일→확실 정답→3일 뒤 해결 | 예정일 전 거절, 애매 정답 재활성, 재시도 중복, 재학습만으로+15 불가·문제 뽑기 함께 필요, full_relearn 키 재사용/다른 입력 |
| custom/more | 실제 문항 수 반환 | 더 풀기 후보0/1/4개는 준비 실패·5개 성공, 미완료단원 제외, 첫 회독 low 강제, custom 점수 반영 |
| 튜터 | 일반 질문·쉬운 설명·근거 | history2개 거절, 다른 사용자 근거 거절, 없는 PDF 페이지 생성 금지, backup 불일치 실패 |
| 일정 | once/future 삭제·빈시간 적용 | 원래 회차 ID 유지, 이전 예외 보존, 날짜42일 경계, 일정 겹침 합집합, 기록 태스크 보존 |
| 월간 | 완료량/시간/성적 집계 | 2월/윤년/월경계/미래월/0분모, 과거 월을 현재 누적 진도로 덮어쓰지 않음 |
| 데모 | empty/day9/overdue 전환 | A reset이 B에 영향 없음, seed값 지속, next-day 재시도키로 날짜 두 번 증가 방지 |

## 구현 진행 순서와 종료 조건

1. 명세 리뷰: FE 전달표 C01–C22와 추가 필드/호환성 변경을 확인한다. 운영 한도·AI 품질은 별도 연동 확인 목록으로 관리한다.
2. 계약별 요청/응답 모델과 테스트를 먼저 정의한다. ERD 마이그레이션·저장소·서비스를 도메인별 원자 커밋으로 연결한다.
3. 현재 학습 흐름의 계약 위반 수정 후 온보딩→자료→계획 승인 흐름을 완성한다.
4. 위 경계 시나리오와 FE 실제 mock 해제 흐름을 검증한다. 명세 인덱스 검증 통과를 기능 테스트 통과로 보고하지 않는다.

원문 회귀 기준: 과목당PDF2개에서 각1쪽을 별개로 집계;140p/8일의 밀림8p=carry·9p=replan;23:30 전후 P1;홈/월간 보충 포함과 과목 진도 보충 제외;문항 [다음] 후 새로고침 답 복구.
