## 아직 계약을 확정할 수 없는 부분

1. 다중 자료에서 기존 unitNo만 쓰는 more/relearn/custom/record/단원 편집 API는 모호하다. unitId와 materialId 또는 ranges로 바꿔야 하며 FE adapter 전반 변경이 필요하다. 현재71개 경로 존재 여부만으로 이 계약의 완성을 판단하지 않는다.
2. 자료별 concept 시험범위 체크(PDF-08)는 FE 단원 단위 bool만으로 표현되지 않는다. conceptId/inScope 저장·수정 계약이 추가로 필요하다.
3. S11 반복 일정 시간 수정은 FE에 삭제/voice 경로만 있어 명시적인 수정/미리보기 계약이 필요하다.
4. S13·S14 과목 추가/재생성과 FE의 축소 결정은 릴리스 포함 범위 확인 전까지 제품 미지원으로 고정하지 않는다.
5. PDF p.22의 PPT, OCR 품질 기준, 분석 통과 기준, 사전 문항 수, 근거 위치 출력, 중간 자료 추가 AI 지원은 여전히 원문 자체의 미확정 항목이다.

따라서 문서 상태는 **원문 대조 반영 초안 / 미해결 계약 존재**이다. 이 문서를 최종 확정본으로 머지하거나 런타임 전체 구현을 시작하지 않는다. 명확한 제품 규칙 교정과 설계 제안을 구분한다.
