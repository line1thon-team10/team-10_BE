## 적용 기준과 충돌 기록

FE의 경로·입출력을 기본으로 유지한다. 요구사항/와이어와 충돌하면 BE 0.7 명세를 대조해 유효한 의미를 채택한다. BE도 충돌하거나 필요한 표현이 없으면 새 계약을 정의한다. 사용자 지시에 따라 충돌 항목을 묵인하거나 FE 축소안을 제품 요구로 확정하지 않는다.

**이전 정의→문제→원문/BE 근거→최종 결정→FE/BE 영향은 [FE 전달표 C01–C22](frontend-handoff.md)에 모두 기록했다.** 'BE 0.7'과 '이번 PR의 교정 전 BE Markdown 초안'을 구분한다. FE의 자료 목록 files[]는 원래 다중 PDF를 지원하므로, 이를 FE 오류로 지적하지 않는다.

## 외부 계약과 별도인 확인 항목

PDF p.22–23의 OCR 품질 기준, 분석 통과 품질, 사전 문항 수/실제 AI 위치 출력, 중간 자료 추가 AI 지원, 시연 패키지 값은 실제 연동 검증이 필요하다. PPT는 현 PDF API 범위에 넣지 않는다. 품질 미확정 상태를 '모든 OCR 퀴즈 금지' 같은 임의 규칙으로 대체하지 않는다.

업로드 크기·서버 AI 처리 예산은 운영 정책이며 기존50MiB/25초를 제품 확정값에서 철회했다. 2026-11-14 실행 중 POL-02에서25MiB/동기20초/PDF작업300초의 초기 운영 설정을 따로 정했으며 성능 실측값이 아니다. 후보는30분 고정 만료 대신 날짜/의존 버전으로 검증한다. 계획 가중치의 항별 상세 함수는 POL-01 allocation-v1의 BE 정책이며 원문 수치와 구분한다.

POL-03은 pinned AI에 있던 텍스트 품질 휴리스틱과 보고서 형식을 확인했다. 네이티브 PDF와 합성 추출 결과를 대조했고, 분석기에 품질 함수 호출이 빠진 점을 M-02 보완으로 명시했다. 실제 OCR 출력의 적합성은 아직 AI-02 대상이다. [자료 정책](material.md)의 pass/no_quiz/failed 구분이 제품 응답 기준이며 실호출 검증 완료를 뜻하지 않는다.

상태는 **FE 전달용 계약 정리 완료 / 구현·통합 검증 전**이다. 원문이 실제로 미확정인 AI 품질/운영 값을 검증 완료로 보고하지 않는다. 원문에 없는 이번 설계(범위 DTO·후보 ID·답안 revision·좌표 형식)는 C01–C22에 새 정의임을 표시했다.
