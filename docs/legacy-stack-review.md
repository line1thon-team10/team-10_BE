## 별도 분기 PR #2

`feat/domain-repositories`의4785bdb는 통합 브랜치의 조상이 아니다. 따라서 내용 전체가 이미 병합됐다고 표시하거나 중복 merge하지 않는다.

- 기존 익명 UUID 검사와 세션 저장소 연결은 현재 #7의 사용자 도메인/트랜잭션 구현이 대체한다. 과거 auth/router를 다시 적용하면 최신 헤더/입력/원자성 처리를 덮을 수 있다.
- 구형 단일 `docs/api-contract.md`는 현재 도메인별 계약과 충돌 해소 문서가 대체한다.
- 36개 테이블의 범용 CRUD 저장소는 현행 앱에서 import하지 않는다. 현재 작업은 소유권과 aggregate별 동작을 가진 저장소를 각 task에서 구현하는 방식이다. 범용 클래스가 존재한다는 이유로 해당 도메인이 완료된 것은 아니다.
- branch와13개 원자 커밋은 보존한다. 최종 승격 때 현재 도메인 저장소 대응을 다시 확인하고, 필요한 독립 변경이 남으면 해당 task로 옮긴 뒤 PR을 대체 처리한다. 현재는 닫거나 삭제하지 않았다.
